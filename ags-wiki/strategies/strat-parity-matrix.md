# Per-rule mutation/parity matrix

> [!note] The real-corpus dogfood is presence-only over messy
> multi-rule files — when it diverges you cannot tell *which* rule
> disagreed. This injects exactly **one** rule's violation into a
> known-clean base and cross-checks Rust vs python-ags4 per rule, with
> the *real* `classify()`/`run_py()` (no logic duplicated → no drift).

## Where it lives / how to run
- `repo:rust-packages/laterite-ags4-corpus-qa/src/parity.rs` test
  `parity_matrix_dogfood` (in-crate, `#[ignore]`).
- `cargo test -p laterite-ags4-corpus-qa parity_matrix_dogfood -- --ignored --nocapture`
- Emits `ags-wiki/.bootstrap/probes/parity-matrix.{md,json}` (the
  durable artifact this page points at — never hand-edited).

## What it found (first run = real gaps, not test bugs)
> [!divergence] Two `assert_clean` rows failed the first run and were
> kept as honest `characterise` rows (the matrix doing its job):
> - **Rule 1 (valid extended `U+00A3`)** → Rust FYI-only, python
>   silent: the [[O-01]] divergence; `reconcile()` has **no O-1 arm**.
> - **Rule 5 (unquoted field)** → python attributes **Rule 3** (or 4 by
>   position), Rust always Rule 5; [[O-03]]'s arm covers only the
>   Rule-4 variant → the Rule-3 variant is **unreconciled**.
> Both feed [[parity-cascade-unreconcilable]].

## Coverage (honest split)
- **9 asserted-clean** (regression-guard the clean-room claim — must
  reconcile): Rule 1-invalid-byte (O-32), 2b, 3, 4, 7, 8, 13, 15 — all
  `AGREE`.
- **characterise-only**: Rule 1-valid-extended, 5, 9, 19.
- **13 differential blind spots** (no faithful single-rule mutator from
  a PROJ/TRAN/UNIT/TYPE base — the "zero parity evidence" by-product):
  Rules 2a, 10a, 10b, 10c, 11a, 11b, 11c, 12, 16, 16a, 18, 18a, 20
  (each with a reason in the artifact). These need a relational
  LOCA→SAMP / ABBR base — supplied by [[laterite-ags4-forge]]'s Mode-B
  synthesizer (the "next extension", now built).
