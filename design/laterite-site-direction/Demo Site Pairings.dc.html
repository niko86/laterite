Turn 3 · 1c + 2b, saturated

The log rail on the bedrock pairing

Scroll inside the frame. Four moves buy the boldness without leaving the ramp: the veil ahead of the probe drops from 88% to 52%, so the whole profile stays coloured; the interactive layer climbs from maroon to rust #ce5640 while maroon keeps the headlines and links; every group is keyed to its own stratum — chip, table cap, KEY edge and rail band are one colour; and the KEY tint goes to 18%, the top of the range the system allows.

3b is the same page on the dark theme — warm brown-black canvas, sand accent, the band ramp shifted one step lighter so it holds on the dark canvas. One honest limit in both: band colour never sets text. Sand on #faf7f5 is about 2.4:1, so the bands appear as fills with dark maroon or stone type on them — headings stay maroon and body stays stone, or the page stops being readable.

Turn 2 · aside · strata as a scroll rail

Scrolling the page as descending a borehole

Both mockups run the 1c pairing and scroll inside their own frame — drag or wheel over each one. The strata bands are the logo's, in ramp order; a steel probe descends with the scroll and uncovers the layers below it, and the readout treats scroll position as depth to 25.00 m — the same 2DP a real LOCA_FDEP carries.

Worth saying plainly: the system bans decorative gradients everywhere except the 3px strata bar. 2a is that bar stood upright, which stays inside the rule. 2b is the idea taken seriously as an instrument — better, and further from the rule. Nothing here animates on its own; it only tracks scroll, so reduced-motion is unaffected.

Turn 1 · demo site · colour + type

Four pairings for the same page

The same slice of the demo site — masthead, hero, one spotlight group table, the findings panel — drawn four ways. No new hues: every value is an existing step of the sampled strata ramp, the steel or the stone neutrals. 1a is what is live today; 1b, 1c and 1d each move colour and type together on one named axis. The three display faces are the substitutions the system already flagged as unconfirmed.

Read them at the pairing level, not the pixel level: the hero, the group code chip, the KEY tint and the verdict banner are the four places a decision here actually shows up on the page.
